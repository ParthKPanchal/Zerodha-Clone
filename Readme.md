## Zerodha Clone — Full-Stack Trading Platform

A full-stack trading platform inspired by Zerodha, developed as part of the **Apna College Delta 7.0 course assignment**. The project was completed within a **1-week deadline** to demonstrate practical knowledge of full-stack web development, REST APIs, authentication, database integration, and responsive UI development.

### Key Features

* Implemented **JWT-based authentication and authorization** for secure user signup and login.
* Users can **register and log in**, after which they are redirected to their personalized trading dashboard.
* Dashboard displays **holdings, positions, orders, and stock information**.
* Users can place buy/sell orders and **increase or decrease stock quantities** through the trading interface.
* Implemented RESTful APIs for authentication, orders, holdings, and positions.
* Integrated **MongoDB Atlas** with **Mongoose** for database management.
* Structured the backend using the **MVC (Model-View-Controller) architecture** for better organization and maintainability.
* Built the backend using **Node.js and Express.js**.
* Developed the frontend using **React.js, React Hooks, HTML5, CSS3, JavaScript, and Bootstrap**.
* Used **Font Awesome** icons to enhance the dashboard interface and user experience.
* Connected the React frontend with the Node.js/Express backend using **Axios**.
* Deployed the backend using **Render** and the frontend/dashboard using **Netlify**.

### Technology Stack

**Frontend:** React.js, React Hooks, JavaScript, HTML5, CSS3, Bootstrap, Font Awesome, Axios

**Backend:** Node.js, Express.js, REST APIs, JWT, MVC Architecture

**Database:** MongoDB Atlas, Mongoose

**Tools & Deployment:** Git, GitHub, Render, Netlify, VS Code

### Use Case

The application simulates a basic online stock-trading platform where users can securely create an account, log in, access a trading dashboard, view their stock holdings and positions, and place buy/sell orders. The project demonstrates how a modern frontend application communicates with a RESTful backend and persists user and trading data in a cloud database.

### Assignment Objective

The primary objective of this project was to apply concepts learned throughout the **Apna College Delta 7.0 Full-Stack Development course** by building a functional full-stack application under a **strict 1-week deadline**. The project served as a practical showcase of my ability to design, develop, integrate, and deploy a complete web application from frontend to backend and database.
